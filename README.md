# GCI World 2026: Global Consumer Intelligence & Data Science

Welcome to my repository for the **GCI World 2026** program offered by the **Matsuo-Iwasawa Lab at the University of Tokyo**. This repository documents my coursework, machine learning competition models, feature engineering pipelines, and end-to-end data science projects

> "Data science is not merely about fitting complex models; it is about engineering actionable intelligence from raw structured data to solve high-stakes business problems."

## 🌐 Overview
GCI World is an international data science and artificial intelligence program designed by the Matsuo-Iwasawa Laboratory. The curriculum spans fundamental data manipulation, supervised/unsupervised machine learning, advanced feature engineering, competitive modeling, and business application tracks like time series and marketing analytics

This repository serves as a complete execution log for all 8 official assignments, the machine learning competition, and the capstone analytical project

## ⚙️ The Methodology
Achieving top-tier predictive accuracy and business value requires strict technical discipline:
1. **Exploratory Data Analysis (EDA):** Dissecting distribution, variance, missingness, and structural anomalies in raw datasets.
2. **Robust Feature Engineering:** Creating domain-specific features, handling high-cardinality categoricals, and applying leakage-free scaling.
3. **Model Selection & Evaluation:** Training supervised algorithms, evaluating metrics (ROC-AUC, F1, RMSE), and optimizing cross-validation strategies
4. **Competitive Modeling:** Iterating hyperparameter tuning and model ensembling to achieve optimal leaderboard placement
5. **Business Recommendation:** Translating model outputs into actionable strategic insights

## 🧠 What I’m Learning

### Part 1: Foundations & Scientific Computing
* **Data Manipulation:** Vectorized matrix computations with `NumPy` and analytical operations via `Pandas`
* **Data Visualization:** Exploratory plots and statistical charts using `Matplotlib`
* **Statistical Foundations:** Inferential statistics, probability distributions, and hypothesis testing

### Part 2: Machine Learning & Competition
* **Supervised Learning:** Classification and regression pipelines using `Scikit-Learn`
* **Model Evaluation & Validation:** Cross-validation, confusion matrices, ROC curves, and bias-variance tradeoff analysis
* **Feature Engineering:** Advanced feature extraction, encoding techniques, and dimensionality reduction
* **Unsupervised Learning:** Clustering methodologies and pattern discovery

### Part 3: Specialized & Business Analytics
* **Time Series & SQL:** Temporal sequence modeling and relational data retrieval
* **Marketing & Business Applications:** Data-driven decision frameworks for consumer intelligence
